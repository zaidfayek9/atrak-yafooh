# عطرك بيفوح

موقع لدار عطور سعودية، بتصميم داكن بلمسات ذهبية، مكتوب بالعربية من اليمين لليسار، ومصمم للجوال أولاً.

## القصة

جاتني الفكرة من أغنية سمعتها لجدل. وأنا عشت في السعودية، وطول الوقت أحاول أسوي شي مميز لمكان أحبه. هذا الموقع هو هذا الشي للسعودية.

## وش فيه

- المجموعة: ثمانية عطور مع فلتر حسب العائلة العطرية (عود، عنبر، زهري، منعش).
- بطاقات تنقلب ثلاثية الأبعاد تعرض تفاصيل كل عطر: على الكمبيوتر تظهر التفاصيل عند مرور الماوس، وعلى الجوال بالضغط.
- مجلة الدار: ثلاث مقالات عن العود والعنبر وورد الطائف.
- شخصية سعودية بالبكسل تمشي معك في الصفحة وتعلّق على كل قسم.
- فيديو متحرك مرسوم بالكود على canvas، مع موسيقى مولّدة بـWebAudio بدون ملف صوت.
- عد تنازلي لجمعة الدار (الجمعة البيضاء).
- نماذج: التسجيل برقم الجوال (واتساب) وطلب عرض، مع تحقق من رقم الجوال السعودي.

## التقنية

موقع ثابت بـHTML وCSS وJavaScript خالصة، بدون أي إطار عمل ولا مكتبات ولا خطوة بناء. الخطوط والصور محلية، والمسارات نسبية فيشتغل على GitHub Pages من أي مجلد.

## English

Arabic-first (RTL), mobile-first static website for a Saudi perfume house. Plain HTML, CSS and JavaScript with no frameworks: 3D flip cards, a canvas-drawn video scene with WebAudio-generated music, a pixel mascot and a countdown to White Friday. Inspired by a song by Jadal, and built as something special for Saudi Arabia, a place the author lived in and loves.
