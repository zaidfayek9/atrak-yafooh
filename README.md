# عطرك بيفوح | Atrak Yafooh

موقع تعريفي بصفحة واحدة لدار عطور سعودية فاخرة، تصنع دهن العود والعنبر والورد الطائفي في توقيعات عطرية. التصميم عربي بالكامل من اليمين لليسار (RTL).

**الرابط المباشر:** https://zaidfayek9.github.io/atrak-yafooh/

## أقسام الموقع
- **الواجهة (Hero):** تعريف الدار وشعارها.
- **مجموعة الدار:** العطور المعروضة.
- **الرحلة:** أربع محطات قبل أن تصل الزجاجة.
- **خريطة العطر:** من الدقائق الأولى حتى ثبات العطر على الثوب.
- **دليل الاختيار:** ثلاث خطوات إلى عطرك.
- **باقات الدار:** الأسعار والباقات.
- **من أوراق الدار:** المجلة والمقالات.
- **جمعة الدار:** العرض الموسمي.
- **اطلب عرضك العطري:** نموذج الاستشارة.

## النشر
الموقع ثابت (HTML + CSS + JS) بدون خادم أو أدوات بناء. يُنشر عبر GitHub Pages من الفرع `main` والمجلد الجذر `/`. كل المسارات نسبية، فيعمل تحت المسار الفرعي `/atrak-yafooh/`.

## التحديث
1. عدّل الملفات (`index.html`، `css/`، `js/`، `image/`، `fonts/`) ثم ارفعها على الفرع `main`.
2. بعد دقيقة تقريبا يتحدث الموقع تلقائيا.

## الهيكل
```
index.html
css/style.css
js/main.js
image/
fonts/
```

## English
Single-page Arabic (RTL) website for a luxury Saudi perfume house, "Atrak Yafooh" (oud, amber, Taif rose). Static HTML/CSS/JS, no build step.

- Live: https://zaidfayek9.github.io/atrak-yafooh/
- Sections: hero, collection, journey, scent map, guide, pricing, journal, seasonal offer, consultation form.
- Deploy: GitHub Pages from `main` / root. Asset paths are relative, so it works under the `/atrak-yafooh/` subpath.
- Update: edit files, push to `main`, Pages redeploys in about a minute.
